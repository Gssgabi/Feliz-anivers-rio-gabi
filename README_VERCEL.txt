Site pronto para Vercel
=======================

Esta pasta já está pronta para deploy como site estático.

Opção 1 — painel da Vercel:
1. Acesse https://vercel.com/new
2. Faça upload desta pasta ou do ZIP.
3. Defina o diretório raiz como a própria pasta do projeto.
4. Deploy.

Opção 2 — via CLI:
1. Instale: npm i -g vercel
2. Entre na pasta do projeto
3. Rode: vercel

Arquivos principais:
- index.html
- _assets/
- vercel.json
